# Silky Nest — Luxury Shopify Theme

Single-product premium theme for **Silky Nest Hair Oil** (`silkynest.store`).

## Demo preview (static)

Open locally:

```
preview/index.html
```

## Shopify install

1. Zip theme folders: `assets`, `config`, `layout`, `locales`, `sections`, `snippets`, `templates`
2. Shopify Admin → Online Store → Themes → Upload zip
3. Or use: `silky-nest-luxury-theme.zip`

## Homepage structure

- Hero banner (`image-4.jpg`)
- Featured product (ATC)
- 3 benefit category banners
- How to use
